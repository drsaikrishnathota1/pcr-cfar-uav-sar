# Computers & Electrical Engineering — Editorial Manager pack

Article type: **Research Paper** (not a VSI).  
Journal: *Computers & Electrical Engineering*.

Use the files in this folder only. Do not upload `paper/submission/` lock files or Markdown sources.

Manuscript file: `Manuscript.docx` (KNOSYS-style Word layout, seven embedded figures, OMML equations).

## What to select in Editorial Manager

### First “Choose file type” list

| EM file type | File to upload |
|---|---|
| **Title page with author details** | `Title_page_with_author_details.docx` |
| **Manuscript** | `Manuscript.docx` |
| **Cover letter** | `Cover_letter.docx` |
| **Declaration of competing interests** | `Declaration_of_competing_interests.docx` |

### Second “Select file type” list

| EM file type | File to upload |
|---|---|
| **Highlights** | `Highlights.docx` |
| **Figure** | `Figure_1.tif` … `Figure_7.tif` (seven separate uploads) |
| **Table** | `Table_1.docx` … `Table_5.docx` (five separate uploads) |
| **Graphical abstract** | `Graphical_abstract.tif` |
| **Supplementary material** | `Supplementary_material.docx` |

Do **not** upload: Response to reviewers, LaTeX source files, Audio/Video, co-submission to Data in Brief, co-submission to MethodsX.

## Suggested upload order

1. Title page with author details  
2. Manuscript  
3. Highlights  
4. Figure 1–7  
5. Table 1–5  
6. Graphical abstract  
7. Cover letter  
8. Declaration of competing interests  
9. Supplementary material
